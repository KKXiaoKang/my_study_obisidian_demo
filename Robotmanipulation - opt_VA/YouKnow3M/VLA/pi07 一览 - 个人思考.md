- 总结
该模型的核心方法在于多样化的上下文条件化 (diverse context conditioning)，这使得它能够有效利用包括机器人示教数据、次优自主数据（包括失败案例）以及非机器人数据（如人类视角视频和多模态网络数据）在内的广泛异构数据集进行训练。与传统的仅依赖语言指令的 VLA 模型不同，π0.7 的 prompt 或 context 被扩展为包含更丰富的信息，不仅描述“做什么”，还描述“如何做”。

- 核心方法论 (Core Methodology) 及技术细节：
    
    - π0.7 的架构基于 π0.6-MEM，总参数量约 50 亿，其中包含一个 40 亿参数的 Gemma3 VLM (Vision-Language Model) 作为骨干网络，以及一个 8.6 亿参数的“动作专家”(Action Expert)。
        

- 在训练期间，模型会随机 dropout prompt 的各个部分，这赋予了 π0.7 在测试时使用 prompt 子集（例如，有无子目标图像）的灵活性。对于子目标图像，训练时仅向 25% 的样本添加视觉子目标图像，且在有子目标图像的样本中，30% 的时间会 dropout 子任务指令。元数据有 15% 的概率完全 dropout，每个单独组件有 5% 的概率单独 dropout。控制模式不会 dropout。
    

- 模型架构和训练: π0.7 采用了来自 MEM 的历史视觉编码器，对最多 4 个摄像机视角（前、双腕、可选后）的最多 6 帧历史图像进行处理，并压缩为固定数量的 tokens。输入图像大小调整为 448x448 像素。视觉编码器还处理最多 3 个子目标图像。π0.7 还将机器人的本体感知状态 $$Q_t$$嵌入到骨干网络中。动作专家预测 50 步的动作块，并使用自适应 RMSNorm 注入时间步信息。模型还使用了训练时实时动作分块 (RTC) 来生成平滑动作轨迹。
    

- 思考
    
Motivation 语言模型已经证明，大规模多样数据能够带来组合泛化，那么机器人模型也不应该只依赖干净的人类 demonstration，而应尽量利用更丰富的数据来源。真正的问题不是“数据太杂不能用”，而是模型缺少足够的信息去判断每条轨迹到底代表什么任务目标、什么执行策略、什么质量水平。因此，与其过滤掉低质量或失败数据，不如给模型更多上下文，让它学会在不同条件下选择该模仿哪一种行为。

- Insight π0.7 的核心 insight 是：把 heterogeneous data 的歧义显式写进 context。也就是说，除了 task instruction 之外，再给模型“怎么做”条件，包括 subtask instruction、描述近未来目标状态的 subgoal image、表示轨迹速度/质量/是否犯错的 episode metadata，以及 control mode。这样，高质量轨迹、低质量轨迹、失败片段和不同策略，就不再是互相冲突的监督信号，而是被 condition 过的不同 mode。
    
- Main Method diverse prompting。 Subtask instruction；Subgoal image由轻量 world model 在线生成多视角近未来目标图，补充语言难以表达的执行细节。 Episode metadata显式标注 speed、quality、mistake，让模型理解 mixed-quality trajectory 的含义，并在推理时通过 metadata prompting 指定期望行为模式。
    
- 一些思考：感觉目前VLA是有着往WAM方式发展的趋势的，这篇工作的重点更像是在数据层面做的提升，感觉模型架构并没有很大的创新。对于数据的精准标注应该是耗时耗力的，而且实际的效果目前不开源也是真的不好说的。
