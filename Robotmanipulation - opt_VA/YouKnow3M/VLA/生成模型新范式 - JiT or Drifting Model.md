# JiT 与 Diffusion Policy、Flow Matching 对比

在理解了传统 **Diffusion Policy (DP)** 的 $\epsilon$-prediction（预测噪声）和 **Flow Matching (FM)** 的 $v$-prediction（预测速度场）之后，我们来看 **JiT (Just image Transformers)**。

**JiT 的核心观点非常“反直觉”但极其深刻：它认为在处理高维原始数据（如像素、原始动作轨迹）时，回归“干净数据” $x$ 本身，要比回归“噪声” $\epsilon$ 或“速度” $v$ 容易得多。**

以下是 JiT 与 DP、FM 在工作原理上的详细对比。

---

## 1. 核心差异：流形假设 (Manifold Assumption)

JiT 的理论基础是：自然数据（图像、有效的动作序列）通常分布在嵌入高维空间中的**低维流形**上。

- **对于 DP 和 FM**：它们预测的是噪声 $\epsilon$ 或速度 $v$（例如 $v = x - \epsilon$）。噪声遍布整个高维空间，它是“离流形（Off-manifold）”的。预测这种弥散在全空间的信号，对模型的容量（Capacity）要求极高。
- **对于 JiT**：它让模型直接预测干净数据 $x$（$x$-prediction）。即使网络容量不足，它也只需要学到那个低维流形即可，不需要理解高维噪声的每一个维度。

---

## 2. JiT 的训练与推理流程

JiT 在数学框架上采用了 **Rectified Flow (FM)** 的线性路径，但把模型的**直接输出目标**改成了干净样本 $x$。

### 训练阶段 (Training)

在每一个训练步：

1. **线性插值**：生成加噪样本

   $$z_t = t \cdot x + (1 - t) \cdot \epsilon$$

   （这里 $t=1$ 是数据，$t=0$ 是噪声。）

2. **网络预测**：模型 $net_\theta$ 输入 $z_t$ 和 $t$，**直接输出**预测的干净样本 $\hat{x}$。

3. **损失计算**：虽然预测的是 $\hat{x}$，但 JiT 发现使用 **$v$-loss** 效果最好。它通过公式把 $\hat{x}$ 转换成预测的速度 $\hat{v}$：

   $$\hat{v} = \frac{\hat{x} - z_t}{1 - t}$$

   然后最小化

   $$L = \|\hat{v} - (x - \epsilon)\|^2$$

### 推理阶段 (Sampling)

1. 从纯噪声 $z_0 = \epsilon$ 开始。
2. **每一步循环**：
   - 模型预测干净样本：$\hat{x} = net_\theta(z_t, t)$。
   - 计算当前速度：

     $$\hat{v} = \frac{\hat{x} - z_t}{1 - t}$$

   - 更新位置（欧拉积分）：

     $$z_{t+dt} = z_t + dt \cdot \hat{v}$$

3. 迭代完成，得到 $z_1 \approx x$。

---

## 3. 三者对比表

| 特性 | **DP (Standard)** | **FM (Standard)** | **JiT (Back to Basics)** |
| :--- | :--- | :--- | :--- |
| **网络直接输出** | 噪声 $\hat{\epsilon}$ | 速度 $\hat{v}$ | **干净数据 $\hat{x}$** |
| **预测目标特性** | Off-manifold (高维弥散) | Off-manifold (高维弥散) | **On-manifold (低维流形)** |
| **高维稳定性** | 在极高维(如大 Patch)易崩溃 | 在极高维(如大 Patch)易崩溃 | **极高维下依然强劲** |
| **对架构依赖** | 强依赖 U-Net 的信息瓶颈设计 | 强依赖大参数量网络 | **普通的 Transformer 即可** |

---

## 4. 为什么这对“动作预测”很重要？

如果你在做机器人动作预测（Action Prediction）：

- **DP/FM 的逻辑**：模型在学习如何从一个混乱的动作轨迹中识别出“噪声分量”。如果动作空间维度很高（比如多指灵巧手或长序列），模型很难精准预测出所有维度的噪声细节。
- **JiT 的逻辑**：模型只需要记住“有效的动作长什么样”。即使动作序列的维度高达几千，模型只要能把当前带有噪声的状态 $z_t$ 投影回“有效动作流形”上即可。

**总结 JiT 的工作方式：**

它像是一个**智能投影仪**。无论当前的动作序列由于加噪变得多么混乱，JiT 总是尝试直接回答：“如果你把这些杂质去掉，那个原本完美的动作序列是什么样的？” 这种策略让它在面对极高维度的原始像素或复杂动作空间时，比试图精确模拟噪声的 DP 和 FM 表现得更加稳健。

**值得验证的下一步：**

在你的机器人任务中，如果增加动作序列的长度或维度（例如从预测 16 步增加到 128 步），DP 的 $\epsilon$-prediction 可能会因为“维度灾难”导致动作发散，而 JiT 的 $x$-prediction 理论上应该能维持更清晰的轨迹。
