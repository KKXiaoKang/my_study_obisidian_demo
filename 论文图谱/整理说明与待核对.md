## 已在整理节点中纠正或限定的表述

1. **CVAE 的含义**：C 是 Conditional，即“条件”，不是原文件名中的“差分”。文件名保留以免破坏历史链接，正文入口已补正。
2. **OpenVLA 的架构**：原版使用融合 DINOv2 与 SigLIP 的视觉编码器与 Llama 2；原笔记混入的“CLIP＋独立定位模块”不能当作原版标准结构。参见 [OpenVLA 原文](https://arxiv.org/abs/2406.09246)。
3. **Q-chunking 的定义**：关键在动作块空间与多步价值学习；仅相加 log-prob 或把 actor 换成 ACT，不足以说明实现了该方法。参见 [Q-chunking 原文](https://arxiv.org/abs/2507.07969)。
4. **SAC 奖励分析**：把后文对 tanh 熵、Q 绝对值与动作梯度的修正纳入同一诊断节点，保留原来的推理演变，不将其写成已证实的单一根因。
5. **FM 与 DP**：以概率路径、网络输出、训练目标、采样器比较；不采用“FM 非马尔可夫／DP 马尔可夫”的简单分类。参见 [Flow Matching 原文](https://arxiv.org/abs/2210.02747)。
6. **6D 旋转**：连续表示不等于处处梯度平坦，6D MSE 不等价于旋转角误差。参见 [连续旋转表示原文](https://arxiv.org/abs/1812.07035)。
7. **运动规划年份**：*Sampling-based Algorithms for Optimal Motion Planning* 是 2011 年，原综述写成 2001。参见 [原文](https://arxiv.org/abs/1105.1186)。RRT* 与 RRT-Connect 的规则也分别归类。
8. **实现与论文**：GR00T 本地多头、双臂注意力、advantage token、motionWAM 的 detach／单步推理、SARM 的本地配置均按工程或历史快照处理，不归成原论文的默认定义。

## 以后怎样保持图谱清楚

一篇论文可以有多个概念或应用节点，但它们需要指向同一原始来源。不要把“相关”全部画成“继承”；新节点至少连接一个主题和一个有明确理由的已有节点。先更新 Markdown 中的关系表，再更新 Canvas 布局。

新增内容时运行 `python3 论文图谱/_数据/validate.py`，检查节点引用、双链、覆盖情况及 Canvas 文件。此检查验证结构完整性，不验证论文结论。
