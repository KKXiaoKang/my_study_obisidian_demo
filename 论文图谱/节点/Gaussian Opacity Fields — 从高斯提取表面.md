# Gaussian Opacity Fields — 从高斯提取表面

## 节点摘要

**论文 · 06 三维感知与重建**  
高斯表示能否直接定义适合提取的连续表面？

通过高斯体渲染构造 opacity field，识别等值面并采用适应场景复杂度的几何提取，而不是只把高斯中心当点云。

论文使用几何相关正则与基于四面体的表面提取。原笔记原先只有一条 Open3D 安装命令，本节点补上方法定位。
